# Scaled RSD project website

Static website for "Trapezoidal Grid Reconstruction for Efficient Non-Line-of-Sight Imaging".

## GitHub Pages

Upload the extracted files, not the ZIP, to the folder or repository you want to publish with GitHub Pages. Keep `index.html` at the folder root.

If this is a standalone repository, enable GitHub Pages from Settings -> Pages -> Deploy from a branch -> `main` -> `/ (root)`.

Code repository: https://github.com/tmsultan/ScaledRSD-NLOS
